# LangGraph Studio presets

Ready-made inputs and settings for LangGraph Studio (https://smith.langchain.com/studio/?baseUrl=http://localhost:8123).
Generated by `.venv/bin/python scripts/langgraph_assistants.py` from `data/scinsight/role_questions.json`, which is the same
list used for the Flowise conversation starters and the Flowise-vs-LangGraph test set.

## Configured for you: assistants

The script also creates **assistants**: saved configurations of a graph on your LangGraph server. In Studio, pick one in the
assistant dropdown next to the graph name, or under *Manage Assistants*.

| Graph | Assistant | What it does |
|---|---|---|
| `supplier_deep_agent` | Deep agent · standard | The default harness |
| | Deep agent · quick | One contract check, few tool calls, executive summary (fast) |
| | Deep agent · thorough | All analysts, bigger budgets, longer report |
| | Deep agent · executive | Standard research written as at most 8 bullet points |
| `scinsight_supervisor` | SC Agent Manager · pause for approval | Saves the recommendation and pauses (`interrupt`) until you resume |
| | SC Agent Manager · hand back, no pause | Saves and returns at once (what the chat bot uses) |

Harness precedence for `supplier_deep_agent`: code defaults < the assistant's configuration < the *Harness* box of the run.
An empty Harness box `{}` therefore uses the selected assistant's settings.
The current settings, with every value and a one-line explanation, are shown under **Default Configuration** (the assistant's
context). The Input form only takes *Messages* and *Harness*; Studio's raw editor expects JSON. After a run, `harness_used` shows
the settings actually applied.

## Files to paste

| Folder | Use |
|---|---|
| `harness/supplier_deep_agent/*.yaml` | Paste into Studio → Input → **Harness** (YAML) to try a preset for one run |
| `inputs/scinsight_supervisor/<role>.yaml` | 5 questions for that role. Studio → Input → **View Raw** → paste **one** block (between the `---` lines) → Submit. They also work for `scinsight_chat` |
| `inputs/scinsight_<specialist>/<role>.yaml` | The same role questions sent straight to that specialist graph |
| `inputs/supplier_deep_agent/procurement_manager.yaml` | 5 supplier-research inputs for the SPARC Deep Agent (SPARC suppliers) |

## Approving a paused run (`scinsight_supervisor`)

1. Submit a question that proposes an action, e.g. the warehouse transfer. The run stops at **human_approval** and shows the recommendation `REC-…`.
2. Approve as the responsible manager in Swagger (http://localhost:8000/docs → `POST /scinsight/api/v1/decisions/{id}/review`, e.g. with `SCI_WAREHOUSE_KEY`).
3. In Studio, click **Resume** with value `proceed` (or `reject` to withdraw). The graph reads the verified decision back from the API: resuming is not the approval.
